# Braga Saúde — Onboarding Site

> Landing page e site de apresentação do Braga Saúde.  
> Static site com informações sobre o app, equipe e contato.

## 🏗️ Tech Stack

- **Next.js** (React, SSG/SSR)
- **Tailwind CSS** (estilização)
- **Vercel/Cloudflare Pages** (hospedagem)

## 🚀 Quick Start

```bash
cd onboarding-site
npm install
npm run dev      # http://localhost:3000
npm run build    # produção
```

## 🌍 Deploy

O site é servido estaticamente. Deploy via Vercel ou Cloudflare Pages conectado ao repositório.

## 📁 Estrutura

```
onboarding-site/
├── src/
│   ├── pages/           # Next.js pages
│   ├── components/      # React components
│   └── styles/          # CSS/Tailwind
├── public/              # Assets estáticos
└── next.config.js
```
